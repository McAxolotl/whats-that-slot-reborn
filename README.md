# What's That Slot? Reborn

Hold **Left Alt** over an inventory slot to see which items it accepts. Click a matching item in the popup to transfer it from your inventory.

This is a client-side mod for Fabric and NeoForge. REI and JEI integration is optional where compatible releases are available. Servers do not need the mod.

Based on [What's That Slot? by Gegy](https://github.com/Gegy/whats-that-slot). Licensed under [LGPL-3.0-only](LICENSE).
